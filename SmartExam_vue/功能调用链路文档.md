# SmartExam 功能调用链路文档

> 本文档详细记录了前端页面 -> API接口 -> 后端Controller -> Service -> Mapper 的完整调用链路

---

## 一、学生角色功能

### 1. 考试列表功能

**获取可参加的考试列表**

ExamList.vue页面加载 → 调用 `getStudentExamList(userId)` → `/api/exam/student` → ExamController.listForStudent() → ExamService.listForUser() → ExamMapper.listForUser()

**获取考试状态**

ExamList.vue页面加载 → 调用 `getMyRecords(userId)` → `/api/record/user/{userId}` → ExamRecordController.listByUserId() → ExamRecordService.getRecordsWithExamInfoByUserId() → ExamRecordMapper.selectRecordsWithInfoByUserId()

---

### 2. 考试详情功能

**获取考试基本信息**

ExamDetail.vue页面加载 → 调用 `getExamById(examId)` → `/api/exam/{examId}` → ExamController.getById() → ExamService.getById() → ExamMapper.selectById()

**获取考试题目列表**

ExamDetail.vue页面加载 → 调用 `getExamQuestions(examId)` → `/api/exam-question/{examId}/questions` → ExamQuestionController.getExamQuestions() → ExamQuestionService.getExamQuestions() → ExamQuestionMapper.selectByExamId()

**检查考试状态**

ExamDetail.vue进入考试前 → 调用 `getExamStatus(userId, examId)` → `/api/record/user/{userId}/exam/{examId}/status` → ExamRecordController.getExamStatus() → ExamRecordService.getExamRecordStatus() → ExamRecordMapper.selectByUserId()

**开始考试**

ExamDetail.vue点击进入考试 → 调用 `startExam({userId, examId})` → `/api/record/start` → ExamRecordController.startExam() → ExamRecordService.startExam() → ExamRecordMapper.insert()

**提交考试**

ExamDetail.vue点击提交试卷 → 调用 `submitExam({userId, examId, answers})` → `/api/record/submit` → ExamRecordController.submitExam() → ExamRecordService.submitExam() → ExamRecordMapper.updateById() → AnswerRecordMapper.insertBatch()

---

### 3. 我的成绩功能

**获取成绩列表**

MyScore.vue页面加载 → 调用 `getRecordListByUserId(userId)` → `/api/record/user/{userId}` → ExamRecordController.listByUserId() → ExamRecordService.getRecordsWithExamInfoByUserId() → ExamRecordMapper.selectRecordsWithInfoByUserId()

---

### 4. 成绩详情功能

**获取记录详情**

ScoreDetail.vue页面加载 → 调用 `getRecordById(recordId)` → `/api/record/{recordId}` → ExamRecordController.getById() → ExamRecordService.getRecordById() → ExamRecordMapper.selectRecordWithInfoById()

**获取答题详情**

ScoreDetail.vue页面加载 → 调用 `getRecordAnswers(recordId)` → `/api/admin/grading/record/{recordId}/answers` → GradingController.getRecordAnswers() → ExamRecordService.getRecordAnswers() → AnswerRecordMapper.selectByRecordId()

---

### 5. 加入用户组功能

**获取已加入的用户组**

JoinGroup.vue页面加载 → 调用 `getMyGroups(userId)` → `/api/user-group/my-groups/{userId}` → UserGroupController.getMyGroups() → UserGroupService.getMyGroups() → UserGroupMemberMapper.selectByUserId()

**通过分享码查询用户组**

JoinGroup.vue输入分享码查询 → 调用 `getGroupByShareCode(shareCode, userId)` → `/api/user-group/by-share-code/{shareCode}` → UserGroupController.getByShareCode() → UserGroupService.findByShareCode() → UserGroupMapper.selectByShareCode()

**通过分享码加入用户组**

JoinGroup.vue点击加入 → 调用 `joinByShareCode({shareCode, userId})` → `/api/user-group/join-by-code` → UserGroupController.joinByShareCode() → UserGroupService.joinByShareCode() → UserGroupMemberService.joinGroup() → UserGroupMemberMapper.insert()

**退出用户组**

JoinGroup.vue点击退出 → 调用 `leaveGroup({userGroupId, userId})` → `/api/user-group/leave` → UserGroupController.leave() → UserGroupMemberService.leaveGroup() → UserGroupMemberMapper.deleteByUserGroupIdAndUserId()

## 二、教师角色功能

### 1. 考试管理功能

**获取考试列表**

ExamManage.vue页面加载 → 调用 `getExamList(params)` → `/api/exam` → ExamController.list() → ExamService.page() → ExamMapper.selectByCreatorId()

**删除考试**

ExamManage.vue点击删除 → 调用 `deleteExam(examId)` → `/api/exam/{examId}` DELETE → ExamController.delete() → ExamService.removeById() → ExamMapper.deleteById() → ExamQuestionMapper.deleteByExamId()

---

### 2. 考试编辑功能

**获取考试详情（编辑模式）**

ExamEdit.vue页面加载 → 调用 `getExamById(examId)` → `/api/exam/{examId}` → ExamController.getById() → ExamService.getById() → ExamMapper.selectById()

**创建考试**

ExamEdit.vue点击保存基本信息 → 调用 `createExam(data)` → `/api/exam` POST → ExamController.create() → ExamService.createExam() → ExamMapper.insert()

**更新考试**

ExamEdit.vue点击保存基本信息 → 调用 `updateExam(data)` → `/api/exam` PUT → ExamController.update() → ExamService.updateById() → ExamMapper.updateById()

**获取用户组列表**

ExamEdit.vue加载用户组选择器 → 调用 `getGroupList()` → `/api/user-group` → UserGroupController.list() → UserGroupService.listWithMemberCount() → UserGroupMapper.selectGroupsWithMemberCount()

**获取知识点列表**

ExamEdit.vue加载知识点筛选 → 调用 `getKnowledgePointList(creatorId)` → `/api/knowledge-point/creator/{creatorId}` → KnowledgePointController.getByCreatorId() → KnowledgePointService.getKnowledgePointsByCreatorId() → KnowledgePointMapper.selectByCreatorId()

**获取题目列表**

ExamEdit.vue加载题目列表 → 调用 `getQuestionList(params)` → `/api/question` → QuestionController.list() → QuestionService.page() → QuestionMapper.selectByCreatorId()

**获取已选题目**

ExamEdit.vue加载已选题库 → 调用 `getExamQuestions(examId)` → `/api/exam-question/{examId}/questions` → ExamQuestionController.getExamQuestions() → ExamQuestionService.getExamQuestions() → ExamQuestionMapper.selectByExamId()

**添加题目到考试**

ExamEdit.vue点击添加题目 → 调用 `addQuestionToExam(examId, data)` → `/api/exam-question/{examId}/question` POST → ExamQuestionController.addQuestionToExam() → ExamQuestionService.addQuestionToExam() → ExamQuestionMapper.insert()

**移除题目**

ExamEdit.vue点击移除题目 → 调用 `removeQuestionFromExam(examId, questionId)` → `/api/exam-question/{examId}/question/{questionId}` DELETE → ExamQuestionController.removeQuestionFromExam() → ExamQuestionService.removeQuestionFromExam() → ExamQuestionMapper.deleteByExamIdAndQuestionId()

**更新题目分数**

ExamEdit.vue修改题目分数 → 调用 `updateQuestionScore(examId, data)` → `/api/exam-question/{examId}/question/score` PUT → ExamQuestionController.updateQuestionScore() → ExamQuestionService.updateQuestionScore() → ExamQuestionMapper.updateScore()

## 五、注意事项

### 1. 依赖注入问题

GradingController和QuestionController直接注入了AiQuestionServiceImpl实现类，应改为注入接口AiQuestionService

### 2. 未使用的接口

exam.js中的startExam和submitExam函数未被使用（实际使用record.js中的同名函数）

auth.js中的logout接口后端未实现

### 3. 路径命名问题

GradingController路径为/api/admin/grading，但教师也需要使用，建议改为/api/grading
