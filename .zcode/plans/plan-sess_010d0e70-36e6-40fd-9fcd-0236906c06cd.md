# SmartExam JWT 鉴权工程化改造方案

## 现状问题
1. **身份信任前端传参**：开始/提交考试、我的成绩、可参加考试、我的群组、分享码加入等约 10 个接口直接从 URL/body 取 `userId`，可被伪造。
2. **鉴权后门**：`JwtUtil` 兼容旧格式 `token_xxx`（拼 `token_用户ID` 即可冒充任意用户）；`application.yml` 的 `auth.enabled=false` 可整体关闭鉴权。
3. **无角色权限控制**：角色判断只在前端路由守卫，后端任何登录用户都能调用户管理/判卷/删除考试等接口。
4. `AvatarController` 手动解析 Authorization 头，绕过 SecurityContext。

角色约定（与前端一致）：**0=教师，1=学生，2=超级管理员**。

## 后端改造（SmartExam_SpringBoot）

### 1. 堵后门 + 配置化
- `util/JwtUtil.java`：删除 `token_xxx` 兼容逻辑；SECRET/过期时间移到 `application.yml`（`jwt.secret`、`jwt.expiration`），改为 `@Component` 注入配置。
- `application.yml`：删除 `auth.enabled` 开关；新增 `jwt` 配置段。

### 2. 新增 `util/SecurityUtils.java`
- 提供 `getUserId()`、`getRole()`，统一从 `SecurityContextHolder` 取当前登录用户，Controller 一律通过它取身份。

### 3. `filter/JwtAuthenticationFilter.java` 增强
- 解析 token 后将 `userId` 作为 principal、`ROLE_TEACHER/ROLE_STUDENT/ROLE_SUPERADMIN` 作为 authorities 写入 SecurityContext。
- 401 返回统一 `Result` 格式 JSON；白名单与 SecurityConfig 保持一致。

### 4. `config/SecurityConfig.java` 重构
- 删除 `auth.enabled` 分支，所有请求必须过 JWT。
- 增加基于角色的路由权限：
  - `permitAll`：`/api/auth/**`、`/api/captcha/**`、`/captcha-images/**`、`/uploads/**`
  - 超管：`/api/user/**`（用户管理）
  - 教师+超管：考试/题目/知识点/公告/用户组的写操作、判卷与记录删除、`/api/records/stats`、群组成员增删
  - 其余接口：登录即可（学生查考试、交卷、查成绩、群组加入/离开等）
- 配置 `AuthenticationEntryPoint`/`AccessDeniedHandler`，401/403 返回统一 JSON。

### 5. Controller 身份改造（核心：userId 一律取自 token）
- `RecordController`：`/start`、`/submit` 忽略 body 中的 userId 改从 token 取；`/my/{userId}` 三接口改为 `/my`、`/my/exam-ids`、`/my/exam/{examId}/status`；`/stats` 的 creatorId 教师强制取自 token（超管可看全部）。
- `ExamController`：`/available` 删除 `userId` 参数。
- `UserGroupController`：`/my-groups/{userId}` → `/my-groups`；`join`/`leave`/`join-by-code`/`by-share-code` 的 userId 改从 token 取；`addMember`/`removeMember` 保留参数（操作他人）但限教师/超管。
- `AvatarController`：删除手动解析 header 的私有方法，改用 `SecurityUtils`。
- `QuestionController`/`UserGroupController`/`ExamController` 列表的 `creatorId` 过滤参数：教师角色时以 token 身份为准，超管可看全部。

## 前端改造（SmartExam_vue）
1. **api 层去 userId 参数**：`record.js`（getMyRecords、getRecordListByUserId、getUserExamIds、getExamStatus）、`exam.js`（getStudentExamList）、`group.js`（getMyGroups、getGroupByShareCode、joinByShareCode/leave 调用）。
2. **视图层同步更新调用点**：`ExamList.vue`、`ExamDetail.vue`（start/submit 不再传 userId）、`MyScore.vue`、`JoinGroup.vue`、`StudentDashboard.vue`、`TeacherDashboard.vue`（stats 不再自传 creatorId）。
3. `utils/request.js`：增加 403 统一提示。
4. localStorage 中的 user 仅用于页面展示与路由守卫，不再作为身份凭证传给后端。

## 验证
- 后端 `mvn -q compile`（或 package -DskipTests）确认编译通过。
- 前端 `npm run build` 确认无引用错误。
- 若环境允许则启动后端，用 curl 验证：无 token 返回 401、学生调管理接口返回 403、正常登录→查考试→交卷流程可用。
